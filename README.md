# 여행 한국어｜韓國旅遊速成教材

給零基礎台灣旅客的旅遊韓語速成教材，目標是出發前做到：讀得出招牌、開口點餐問路、遇到狀況求得到救。

**線上版：** https://xxcyl.github.io/travel-korean/

- **情境**：打招呼、餐廳、交通、購物、住宿、緊急，每個情境附上會用到的菜名、招牌、數字；可搜尋句子
- **句子卡**：點任何句子即可播放、慢速、收藏、「出示」全螢幕大字給對方看，也能看每個字的拼法和實際唸法
- **跟讀**：一句一句聽語音跟著說；也能在頁面內用 YouGlish 看 YouTube 上韓國人實際說這句的片段
- **練習**：看中文說韓文的自我測驗；依情境產生提示詞，貼到 Gemini、ChatGPT、Claude 等 AI 的語音模式做角色扮演或口說抽考
- **工具**：萬用句型（5 個句型與 예요／이에요）、認字入門（依《訓民正音》設計原理：母音天地人與複合母音、子音依發音部位加劃；拼字積木（27 種收音）、手寫描寫、連讀規則（連音、鼻音化、硬音化、送氣化、ㅎ 弱化）、測驗：解碼招牌／看字選音／拼字挑戰）、40 音表（含拼音表）；子音、母音、收音用固定顏色區分、數字與價錢、出發前準備
- **離線使用**：可加到手機主畫面；打開過一次就能離線開啟，音檔可在「工具 → 離線使用」一次下載（約 5 MB）
- **清單**：收藏的常用句，旅途中最快找到；聽過、收藏等紀錄只存在自己的瀏覽器

## 發音

所有韓文發音都是用開源的 [MeloTTS](https://github.com/myshell-ai/MeloTTS)（MIT）在本機預先產生的 mp3，放在 `audio/`。
沒有對應音檔的文字會改用瀏覽器內建語音。

TTS 唸單一音節不太穩定，所以字母卡會連同例字一起唸（例如 ㅋ →「카, 커피」）。發音以真人為準，這裡只是輔助。

## 修改內容後重新產生音檔

    node extract.mjs                 # 從 index.html 擷取要發音的韓文 → phrases.json
    .venv/bin/python gen_audio.py    # 只產生新句子，並刪掉用不到的舊音檔
    .venv/bin/python gen_pron.py     # 用 g2pkk 產生「實際唸法」→ pron.js（錯誤處在 OVERRIDE 手動修正）

環境建置（macOS / Apple Silicon 上的各種相容問題）見 [SETUP.md](SETUP.md)。
`check_asr.py` 可用 Whisper 把音檔轉回文字，找出可能唸錯的句子。

## 真人片段（YouGlish）

跟讀頁的真人片段來自 [YouGlish](https://youglish.com) 的官方嵌入元件，按下「看真人片段」才會搜尋。
以整句搜尋；沒有片段的句子就只用語音練習。免費版每天有搜尋次數上限，用完時可以改按「在 YouGlish 開啟」。

## 離線與圖示

`sw.js` 是 service worker：頁面與唸法資料先抓網路、失敗才用快取；音檔快取後直接使用（支援 iPhone Safari 需要的 Range 請求）。
改了快取的檔案清單或策略時，把 `sw.js` 裡的版本號（`shell-v1`、`audio-v1`）加一。
`icons/` 是用 Pillow 和 Jua 字型畫的 App 圖示。
